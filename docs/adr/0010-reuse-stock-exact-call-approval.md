# Reuse stock exact-call approval

Profile `before-tool` approval reuses the DSH Tool runtime, Host approval service, audit events, and Conversation UI instead of introducing an Ultra approval protocol. Only `allowed-once` grants the immutable proposed call, later monotonic guards and sandbox enforcement remain independent, and an external provider may advertise the capability only when its native call, decision, and audit identities are the same enforceable correlation.

## Consequences

Missing, malformed, throwing, cancelled, unavailable, or rejected decisions fail closed. A waiting state requires a live same-process or provider-proven pending correlation; an unmatched persisted request is orphaned, non-actionable evidence. Ultra disposal removes only its Hook registrations and pending correlations, never the stock approval service or another provider generation.
